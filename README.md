## 📌 Project Overview

This project is an **interactive Customer Analysis Dashboard created using Microsoft Excel**. 
The dashboard provides a simple and clear view of customer and order data to help understand 
regional performance, product category performance, customer orders, and order status.

## 📈 Dashboard Preview

![Customer Analysis Dashboard](Customer analysis dashboard)

## 🔍 Key Insights

The dashboard includes the following analysis:

- 👥 **Number of Customers by Region** – Compares customers across East, North, South, and West regions.
- 📦 **Orders by Product Category** – Shows the number of orders for Electronics, Clothing, Home & Kitchen, and Beauty.
- 🏆 **Top 5 Customers by Number of Orders** – Identifies customers with the highest number of orders.
- 📋 **Order Status Analysis** – Shows the distribution of Delivered, Shipped, Processing, and Cancelled orders.
- 🌎 **Customers by Region** – Displays the regional contribution of customers using a pie chart.
- 🎛️ **Interactive Filters** – Allows users to filter the dashboard using Product Category and Region.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Filtering
- Data Visualization
- Basic Excel Functions

## 📊 Dashboard Features

- Interactive Pivot Tables
- Pivot Charts
- Slicers for filtering
- Bar Charts
- Pie Charts
- Top 5 Customer Analysis
- Region-wise Customer Analysis
- Order Status Analysis

## 🎯 Project Objective

The main objective of this project is to analyze customer and order data using **Excel** 
and present the results through an easy-to-understand interactive dashboard.
